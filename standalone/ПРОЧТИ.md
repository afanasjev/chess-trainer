# Дебюты для iPhone

`openings.html` — всё приложение в одном файле, без внешних библиотек,
шрифтов и загрузки дебютов. Включены 3 студии, 6 глав и 28 вариантов:
французская защита, новоиндийская защита и ферзевый гамбит.

## Открыть на iPhone через Mac

1. На Mac дважды нажмите **«Запустить на Mac.command»**. Нужен Python 3
   (на этом Mac он уже используется для работы с проектом).
2. В открывшемся окне появится адрес вида `http://192.168.1.10:8765/`.
3. Подключите iPhone к той же Wi-Fi сети и введите этот адрес в Safari.
4. При желании: «Поделиться» → «На экран Домой».

Пока используется такой адрес, Mac должен быть включён, окно запуска открыто,
а устройства — в одной сети. При запросе macOS разрешите входящие подключения.
После смены Wi-Fi адрес может измениться. Для остановки закройте окно запуска.
Сервер отдаёт только приложение, а не остальные файлы проекта.

## Открывать в любом месте

Разместите `openings.html` на обычном статическом веб-хостинге и открывайте его
по полученной ссылке. Этот вариант работает без Mac. Публикация в составе этой
задачи не выполнялась. Само копирование HTML в приложение «Файлы» на iPhone
не заменяет открытие веб-страницы в Safari; рекомендуемый запуск — по ссылке.

Файл автономен по содержимому, но установка значка не обеспечивает его
сохранение для следующего запуска без сети. Кэширование для офлайн-перезапуска
в этой однофайловой версии не добавлено.

## Управление

- Выбор студии, главы, варианта и стороны — вверху, «Дебют, глава и вариант».
- Нажмите фигуру, затем клетку назначения.
- «Изучение» — шаги вперёд и назад без проверки ходов.
- «За обе стороны» — самостоятельно делать ходы белых и чёрных.
- «Случайный порядок» — внутри главы или между главами выбранной студии.
- Есть подсказка, повтор текущего варианта и конечная очередь вариантов.
- Результаты сохраняются в этом браузере на данном адресе; с Mac автоматически
  не переносятся. После обновления незавершённый вариант начинается заново.
- Результаты можно скопировать для анализа в чате.

## Обновление библиотеки

Из корня проекта: `node tools/build-openings-mobile.cjs`.
Команда пересобирает единственный HTML из текущих `dist/openings-data.js`,
`dist/openings.js`, `dist/chess.js` и PGN-файлов. После пересборки перезапустите
окно запуска на Mac и обновите страницу на iPhone.

Проверено автоматически на всех 28 вариантах. Размер экрана iPhone 14:
390 × 844 CSS-пикселя; предусмотрены портретный и альбомный режимы,
квадратная доска, крупные кнопки и поля выбора без автоматического увеличения.
